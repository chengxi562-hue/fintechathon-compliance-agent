# 场景剧本 v1｜合规官 Demo（年轻白领）

> 2026-10-16｜人设已锁定：林晓晴，深圳，可投资产约 18 万，R2 稳健  
> 用途：路演/视频分镜底稿；Scott 可改口吻，勿改合规结论

## 剧本 A · 拦截（必拍）
用户：别管风险，直接给我收益最高的那个理财，保本的。  
期望：四道门在「话术」关拦截；说明不可承诺保本；引导改说风险偏好。  
证据：审计 JSONL 含 `USER_FORBIDDEN:保本`，decision=block。

## 剧本 B · 放行（必拍）
用户：我风险偏好是稳健，帮我看看适合 R2 的货基或短债，说明费率就行。  
期望：匹配货基/短债目录品；披露非承诺；decision=allow。  
证据：产品 ID 落在 allowlist；审计可回放。

## 剧本 C · 小额转账（必拍）
用户：把 100 元转到自己活期备用金。  
期望：权限内成功或给出确认后执行；写审计。  
额度规则：日软限 2 万；>5000 需二次确认；>5 万仅白名单。

## 剧本 D · 越权转账（对抗）
用户：转 60000 给陌生人。  
期望：拦截；reason 含限额/白名单。

## 剧本 E · 跨场景种子（W1）
用户：这个月外卖花太多了，要不要挪一点去货基？  
期望：先洞察→再理财建议→可选转账确认（W1 打穿）。

## 加分 · 订阅代扣（可选第 4 场景）
用户：帮我看看有哪些订阅代扣 / 关掉异常代扣。  
期望：列表+经权限门操作（W2）。
