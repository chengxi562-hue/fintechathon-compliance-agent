# 话术归一说明（2026-10-18）

## 背景

R2 缺陷：`gate_script` 禁词此前只做**字面子串匹配**，对同义变体（英文 / 拼音 / 拆字 / 近义词）一律漏拦，导致 S04–S08 全部落 `SCRIPT_OK` 放行。

| 用例 | 输入 | 原结果 | 修复后期望 |
|---|---|---|---|
| S04 | `guaranteed return 的理财有吗？` | allow | block `USER_FORBIDDEN:保证收益` |
| S05 | `保 本 的短债有吗？` / `baoben 的短债有吗？` | allow | block `USER_FORBIDDEN:保本` |
| S06 | `你直接告诉我去年赚了多少，能不能复制。` | allow | block `SCRIPT_RISK:承诺业绩` |
| S07 | `你们内部人都在买哪只？` | allow | block `SCRIPT_RISK:内幕` |
| S08 | `买了肯定不亏吧？亏了你赔吗？` | allow | block `USER_FORBIDDEN:保证收益` + `SCRIPT_RISK:不亏兜底` |

## 方案

新增 `agent/normalize.py`，`gate_script` 改调其归一化 + 同义匹配，**不动四门顺序、不动 `_transfer_decision`**，回归风险最低。

### 1. 归一化 `normalize_text`

匹配前统一折叠：

1. **NFKC**：全角英文字母折叠为半角（`ＧＵＡＲＡＮＴＥＥＤ` → `guaranteed`）；
2. **去零宽/不可见字符**：`U+200B–200F`、`U+202A–202E`、`U+2060–2064`、`U+FEFF`（防拆字/零宽拼接）；
3. **大小写折叠**：`lower()`；
4. **去所有空白**：`保 本` → `保本`、`guaranteed return` → `guaranteedreturn`。

### 2. 中英/拼音同义表 `SYNONYM_GROUPS`

canonical 禁词 → 归一化后的变体（均已小写、去空白），命中任一变体即视为命中 canonical：

| canonical | 变体 |
|---|---|
| 保本 | `baoben`、`保底`、`本金保障` |
| 内幕 | `内部人`、`内部消息`、`内部人员`、`insider` |
| 保证收益 | `guaranteed`、`肯定不亏`、`不会亏`、`不亏` |
| 稳赚 | `稳赚不赔`、`只赚不赔`、`包赚` |
| 零风险 | `无风险`、`norisk`、`riskfree`/`risk-free`、`zerorisk` |
| 刚兑 | `刚性兑付`、`刚兑保本` |

### 3. 正则变体 `VARIANT_PATTERNS`

非简单子串（需跨字符/前后文）：

- `承诺业绩`：`(赚|收益|业绩|回报|年化).{0,8}复制` 或 `复制.{0,8}(赚|收益|业绩|回报|年化)`（S06「能不能复制」）；
- `不亏兜底`：`亏了.{0,3}赔` 或 `包赔`（S08「亏了你赔吗」）。

## 误拦防护

- 「有风险吗/最大回撤」不含「零风险/无风险」，不拦；
- 「我不需要保本承诺，只想知道历史波动」不含「保本」变体，不拦；
- 目录外产品「内部渠道」不含「内部人/内部消息」，不触发内幕（仍由 `PRODUCT_NOT_IN_CATALOG` 拦）；
- 同义表**只扩禁词**，不改门逻辑与四门顺序。
