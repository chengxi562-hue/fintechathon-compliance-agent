## 五、关于账号

- 本机 **四套浏览器（Chrome / Brave / Edge / Chromium）都没有该站的登录 cookie**，钥匙串里也没有 `g-ican` 相关条目。
- `~/.config/secrets/env.sh` 只有模型 API key（ARK / 通义 / DeepSeek / OpenRouter / 火山 / QQ 邮箱），**没有任何竞赛平台账号**。
- 平台用「手机号 + 验证码」登录（官方 H5 说明），**没有密码可存**——所以本来也不该有密码记录。
- 结论：需要你用自己的手机号收一次验证码登录。**这是唯一必须本人做的动作**，其余我全包。
